## Identity lock

The Since identity represents elapsed time from a meaningful starting point through an open elapsed-time ring, a distinct start-point node, and restrained clock hands. The silhouette is intentionally different from Calendar, Tasks, Memos, and Changelogs.

The canonical color family uses teal through deep teal. Color supports recognition but does not define it; the elapsed-ring/start-node geometry remains the primary identity.

## Android derivative

The Android package keeps only traceable platform derivatives required for adaptive-icon packaging:

- `res/drawable/ic_launcher_background.xml`
- `res/drawable/ic_launcher_foreground.xml`
- `res/drawable/ic_launcher_monochrome.xml`
- adaptive-icon declarations under `mipmap-anydpi-v26` and `mipmap-anydpi-v33`

These files are consumer derivatives, not independent branding authority. Geometry and color changes must originate from the canonical GoreeCloud Branding Assets source before being synchronized here.
